# Ruta Clara | Pico y Placa Colombia

Ruta Clara es una página web informativa para consultar el pico y placa en Colombia de forma rápida, visual y amigable.

El sitio permite que una persona ingrese su número de placa, seleccione ciudad, tipo de vehículo y fecha, para saber si tiene o no restricción de movilidad. También incluye espacios preparados para publicidad y una página de política de privacidad.

---

## Funcionalidades principales

- Consulta de pico y placa por número de placa.
- Vista previa de la placa en formato visual colombiano.
- Placa flotante visible mientras el usuario navega.
- Consulta por ciudad:
  - Bogotá
  - Medellín / Valle de Aburrá
  - Cali
- Visualización de los dígitos con restricción del día.
- Resultado claro:
  - Puedes circular
  - Tienes pico y placa
  - No aplica la medida ordinaria
- Espacios preparados para publicidad.
- Modal de publicidad antes de mostrar el resultado.
- Página de política de privacidad.
- Diseño responsive para celular, tablet y computador.

---

## Tecnologías usadas

Este proyecto está construido únicamente con tecnologías de frontend:

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- GitHub Pages

No requiere backend para funcionar en esta versión inicial.
